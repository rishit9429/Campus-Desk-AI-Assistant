# 🎓 Campus Desk — AI College Assistant

**Your personal academic command center.** Manage your college life, organize your studies, track attendance, and stay productive with Campus Desk.

## 📌 About the Project

Campus Desk is a modern, responsive web application designed to help college students organize their academic activities in one place.

It features a clean dashboard, an academic management interface, and productivity tools designed to make everyday college life easier.

## ✨ Features

* 📊 **Student Dashboard** — Get an overview of your academic activities.
* 📅 **Class Timetable** — Organize your weekly class schedule.
* ✅ **Attendance Tracker** — Monitor attendance and keep track of attendance percentages.
* 📝 **Notes Manager** — Create and organize personal study notes.
* 🤖 **AI Assistant Interface** — An interface for interacting with an academic assistant.
* ⏱️ **Pomodoro Timer** — Manage study sessions and breaks.
* 🃏 **Flashcards** — Support revision and active recall.
* 📈 **GPA Calculator** — Help calculate academic performance.
* 🌙 **Dark Mode** — Switch between light and dark themes.
* 📱 **Responsive Design** — Use the application on desktop and mobile devices.
* 🔍 **Quick Navigation** — Navigate the application using its command interface.

## 🛠️ Technologies Used

* **HTML5** — Application structure.
* **CSS3** — Styling, responsive layouts, themes, and animations.
* **JavaScript** — Interactive features and application logic.
* **Google Fonts** — Typography using Plus Jakarta Sans, Space Grotesk, and JetBrains Mono.

## 🚀 Getting Started

You can run Campus Desk locally on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your actual GitHub username and repository name.

### 2. Open the Project

Navigate to the downloaded project folder.

### 3. Run the Application

Open `index.html` in your web browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.

## 🎯 Project Goals

Campus Desk aims to make academic organization simpler by bringing useful student productivity tools together in one interface.

The project focuses on usability, responsive design, accessibility, and a student-friendly experience.
